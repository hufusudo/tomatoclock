# TomatoClock 本地番茄钟

从应用菜单搜索“番茄钟”即可打开。关闭窗口会退出，未完成的番茄不计入学习记录；最小化时继续计时。工作结束后播放手风琴转场并显示休息图片，倒计时在后台继续；休息结束再转场回计时页，自动开始下一番茄。

## 功能

- 自定义工作时长，自动计算短休和长休，每四个番茄长休。设置页使用三扇区圆盘：悬停轻微突出，点击后颜料铺开，编辑并保存后还原圆盘。
- 准备状态下点击圆圈中央的时间，直接输入 1–180 分钟；Enter 或点击别处保存，Esc 取消。修改同步到设置页；工作、暂停和休息中不能编辑时长。
- 计时主界面点击“编辑快捷项”，在原地配置最多 3 个专注时长（1–180 整数分钟），留空即隐藏；修改后自动保存，点击“收起编辑”或按 Esc 收起。准备状态下点击快捷项，直接以该时长开始番茄钟；所选时长同步为当前工作时长，休息仍按原规则计算。计时、暂停、休息及保存期间不可使用快捷项。
- 工作结束和休息结束时播放手风琴转场及较响提示音；切到其他应用、其他页面或最小化时，到点仍立即响铃，回到窗口不会重复播放。休息页仅显示图片，休息结束自动进入下一番茄。
- 暖白计时页、圆环倒计时和“计时 / 统计 / 设置”三页导航；开始/结束、暂停/恢复切换，按钮带按压反馈。
- 顶部导航按选定的视频动效切换：选中胶囊连续滑移并轻微回弹，当前页面展开名称，其余显示图标；悬停可查看名称，键盘也能切换。系统开启减少动态效果时直接切换。
- 桌面版支持 custom.css 白名单主题变量：背景、文字、强调色、字体、圆环颜色/线宽，以及统计和设置页配色；顶部导航及三个计时按钮的样式和动效固定保护。
- 今日番茄数、今日学习时长、历史累计时长。
- 学习统计以图表代替表格：居中显示当前日期范围、学习时长和番茄数，默认折线图，可切换条状图；保留“按天 / 按周”，按每个已完成工作段的实际设定时长累加。
- 每次进入统计、切换图形、换周或翻页时，折线逐渐绘出、柱条从底部生长；系统开启“减少动态效果”时直接显示。
- 数据仅保存在本机 SQLite，图表也完全离线可用。
- 启动时检查本地新版，提示“立即更新 / 暂时跳过”；一键更新后自动重新打开。
- 计时页使用圆环倒计时；开始键在“开始 / 结束”间切换，暂停键在“暂停 / 恢复”间切换，三枚操作键带按压反馈。
- “计时 / 统计 / 设置”在顶部导航切换。设置页修改时间，统计页保留按天和按周视图。
- 提前结束时未完成的工作段不计入；若按下暂停时番茄刚好到期，先按完成记录，再进入休息。

## 启动与安装

便携成品在 `dist/TomatoClock-linux-x64/`，双击 `start-tomatoclock` 启动。

用户级安装入口是 `scripts/install-user.cjs`；安装到 `~/.local/opt/tomatoclock`，应用菜单入口位于 XDG 用户 applications 目录。只替换本应用文件，拒绝覆盖不能确认归属的同名目录或入口。支持 `--dry-run` 预览及 `--prefix` 临时测试安装。

安装目录中的 `start-tomatoclock` 是固定入口；实际程序放在 `versions/<更新标识>/package`，`current` 指向当前版本。成功更新后保留当前版、上一版和固定启动恢复运行时，自动清理更早的完整旧版本。首次旧平铺安装和额外手动文件保留。

当前 CachyOS / KDE Wayland 上使用已存在的 XWayland 显示通道，解决 Electron 原生 Wayland 最小化/恢复限制。应用与测试均保持 Chromium 沙箱开启，不需要修改桌面、内核或引导配置。

## 数据与备份

默认数据库：`~/.local/share/tomatoclock/learning.sqlite`。若设置了 XDG_DATA_HOME，位于其下的 `tomatoclock/learning.sqlite`。

先关闭应用，再复制 learning.sqlite 即可备份。应用程序目录与数据库分离；更新继续使用原数据库。恢复备份时也应先关闭应用。

一键更新前会自动复制数据库到同目录的 `backups/before-update-*.sqlite`。存在待恢复的 SQLite 事务文件时暂缓更新，先打开当前版恢复数据库。程序恢复不会自动覆盖数据库；今后涉及数据库结构变化的版本必须先明确设计迁移和兼容规则。

“学习记录”中的“导入旧记录”接受网页版导出的 JSON，先预览，确认后写入。同来源同日期替换，重复导入不叠加，桌面完成记录保留。文件最大 1 MiB。导入不删除网页数据。

按周时可选择月份和周次，标题例如“2026年10月第1周”。每周从周一到周日，包含当月1日的那一周是第1周，跨月也显示并统计完整七天（例如9月28日至10月4日）。没有完成记录的日期显示0分。周总时长直接汇总已有每日记录，旧记录和导入记录也可查看，无需升级数据库结构。

统计页默认显示折线图，点击“条状”可比较各天的学习时长；纵轴按数据自动使用分钟或小时。悬停、点选数据点，或用 Tab 聚焦，可查看完整日期、学习时长及番茄数；左右方向键切换数据，Esc 收起详情。按天从最早一条记录的日期开始，连续每7个自然日一页，从早到晚翻页直到今天；没有学习的过去日期和今天显示0分，折线落到零点。横轴每天都显示月/日，跨月也不省略。最后一页保留7个日期，今天之后的日期淡显留空，不画零值点或柱条。按周仍显示完整七天，缺失日期补0。屏幕阅读器仍可读取完整记录明细。计时页、学习记录与数据库格式不变。

本地源码的网页入口包含“导出学习记录”；此前线上网页尚未发布这次更新，因此旧线上数据需要后续发布导出入口或单独导出，桌面版从空记录开始也可直接使用。

## 专注界面与进出动画

点击“开始”或快捷时间后，一圈柔和的冲击波从表盘圆心向外扩散，扫过的区域切换为专注界面，约520毫秒覆盖整个窗口。顶部导航、快捷项与编辑入口、轮次及底部摘要随扩散收起。专注与暂停时只保留表盘、状态以及“结束 / 暂停（恢复）”两个按钮；计时立即开始。

点击“结束”，细指针从表盘中心顺时针转一圈，约650毫秒内沿扫过的区域恢复完整准备界面。提前结束的未完成番茄不计入学习记录。工作完成进入休息、休息结束自动开工仍使用原来的手风琴转场；休息图片返回应用后可使用完整导航。系统开启“减少动态效果”时直接切换，窗口隐藏或调整大小时及时结束动画。

## 圆盘时间设置

设置页点击“工作时长 / 短休微调 / 长休微调”对应扇区，颜色像颜料一样铺满圆盘后进入编辑。可输入整数、拖动滑条或点加减；工作为1–180分钟，短休/长休仍按工作时长计算，微调范围为−5至+5分钟。圆盘内可预览最终休息时间，圆盘下方居中显示已保存的短休和长休。

点击“保存”或按Enter，确认保存成功才收回圆盘；取消、Esc或离开设置页会放弃未提交草稿，修改不会自动保存。保存失败时保留草稿，可直接重试；计时、暂停、休息及记录保存期间不能打开编辑。保存已提交后离页不会撤销写入，但完成时不会重新打开编辑或抢走焦点。系统开启“减少动态效果”时立即切换。

## 专注快捷项

专注快捷项直接在计时主界面配置，无需切换到设置页。编辑输入框后离开该框会自动保存，Esc 收起时放弃当前尚未提交的输入。即使三个快捷项都为空，主界面仍保留“编辑快捷项”入口；开始计时后自动收起编辑器。重启和更新后配置保留。桌面版配置独立位于 `~/.config/tomatoclock/focus-shortcuts.json`（或 XDG_CONFIG_HOME 下），不会修改学习数据库结构。保存失败时保留原配置，快捷启动若无法保存工作时长则不开始计时。

## 休息图片与过场

在“设置 → 休息图片”选择 PNG、JPEG 或 WebP，可随时替换或恢复默认图片。选图保存成功后，图片会复制为应用内部的静态PNG配置，删除、移动或修改原始文件都不会影响已保存的休息图片；重启和更新后保留。普通窗口、最大化及全屏时均按可用区域等比例完整显示图片，不裁剪内容；比例不同时居中留白，也不叠加倒计时。默认使用内置山水图片。

工作结束时，页面以纵向折片收拢，再像手风琴一样从中间展开到图片页；休息结束时反向过场回计时页。每次完整过场约0.8秒，计时始终继续。点击图片或按 Esc 可返回应用而不结束休息；在设置页点击“返回休息图片”可继续显示图片。最小化后只恢复当前阶段，不补播已经结束的休息；系统开启减少动态效果时立即切换。

选图最大16 MiB、约3200万像素，保存时限制最长边2048像素，避免配置不断膨胀。配置只保存一张当前图片，位于 `~/.config/tomatoclock/rest-image.json`（或 XDG_CONFIG_HOME 下）。取消选择、解码/保存失败时保留原图；不覆盖不能确认归属的配置文件，也不接受链接或非普通文件。

## 外观主题

进入“设置 → 外观主题”，点击预览卡片即可切换：

- 原版暖白：保留原有暖白留白和细圆环。
- 纸本书桌：横纹纸面、衬线数字和多层墨线圆环。
- 复古仪表：立体表圈、分钟刻度和琥珀色进度。
- 极简终端：等宽数字、方形框线和深色网格底纹。

主题会同步应用到计时、统计和设置页；顶部导航和开始/暂停/重置三个按钮保持原来的外观、字体和动效。切换主题不影响正在进行的计时。选择成功后仅保存在本机，重启和更新后保留；保存失败时保留当前主题。

主题选择位于 `~/.config/tomatoclock/theme-selection.json`（或 XDG_CONFIG_HOME 下），独立于学习数据库、休息图片和 custom.css。切换内置主题不会覆盖已有 custom.css；点击“自定义主题”可切回自己的配色。首次升级时如果已有 custom.css，继续使用原自定义主题。

### 自定义主题文件

进入“设置 → 外观主题”，展开“编辑自定义主题文件”，点击“打开 custom.css”。首次点击会在 `~/.config/tomatoclock/custom.css` 创建带说明的模板；设置了绝对路径 XDG_CONFIG_HOME 时改用其下的 `tomatoclock/custom.css`。通过系统关联软件打开，使用文本编辑器修改；保存后点击“重新加载主题”会切换并应用自定义主题。当前已选自定义主题时，下次启动也会自动加载。这个文件独立于程序和数据库，升级不会覆盖，程序清理也不会删除。

项目根目录 `custom.css` 是随程序发放的模板，完整列出了可用变量。只读取 `:root { ... }` 中的白名单声明，**不会把自定义文件当作 CSS 样式表加载**。导航和三个计时按钮固定原有字体、颜色、尺寸及动效参数；没有可修改它们的主题变量。选择器、普通样式属性、动画、@import、外部字体/图片、URL、var()、!important 均不接受。未知变量会忽略并提示；格式或值出错时保留当前有效主题。

颜色使用十六进制或 transparent；字体使用本机字体名称列表，不下载字体。圆环线宽为0.5–12的数值，不加单位。各页面变量未设置时继承全局主题，空模板恢复内置主题。主题文件最多32 KiB；不读取链接、目录或其他非普通文件。示例：

```css
:root {
  --theme-background: #101820;
  --theme-text: #e5eef5;
  --theme-muted: #b1c3d0;
  --theme-accent: #53d8b3;
  --theme-border: #304452;
  --theme-surface: #223a44;
  --theme-ring-track: #304452;
  --theme-ring-work: #53d8b3;
  --theme-ring-break: #ffc857;
  --theme-ring-progress-width: 4;
  --theme-font: "Noto Sans", sans-serif;
  --theme-records-font: "Noto Serif", serif;
}
```

## 本地一键更新

从应用菜单打开时检查 `dist/updates/latest.json` 指向的已打包新版。发现不同的、版本号不低于当前版本的更新后，提示“立即更新 / 暂时跳过”；选择更新后先校验、备份、复制，再原子切换程序并重新打开。没有新版或源码目录已移动时，正常打开当前版。

更新检查只在启动时进行。已打开的计时不会被打断，运行时再次点菜单入口只唤起已有窗口。校验或安装失败时继续使用当前版；新版未完成首次启动而失败时，恢复到上一版，并暂时跳过这一份失败的更新包。

更新源的绝对路径写在 `~/.local/opt/tomatoclock/.tomatoclock-install.json`。当前使用本项目的 `dist/updates`，无需联网或服务器。移动项目后需要重新运行安装脚本来设置新位置。更新包只保留最近两份发布；已停止任务的带标记临时目录也会清理。未知文件或被手动修改的版本会跳过。

按你的选择，**学习数据库与全部数据库备份保留，不参与自动清理**。清理只处理程序生成物，更新失败时不会先删除可恢复的旧程序。

以后维护此项目时：修改代码 → 验证相关功能 → 运行 `npm run release:local` → 告知用户下次打开可一键更新。这个命令会打包、运行全部自动测试，通过后才公布本地更新。只保存源码或运行 `package:linux` 不会公布更新。首次安装更新能力才需要运行安装脚本，之后发布新版不需要覆盖正在运行的安装目录。

AI 维护入口固定为 `AGENTS.md`（规则）和 `HANDOFF.md`（当前状态、代码职责）。手动检查清理可运行 `npm run cleanup:preview`，实际清理用 `npm run cleanup`；默认只预览程序清理，不删除旧程序。

## 开发

精确依赖版本见 package.json/package-lock.json。首次安装 Electron 44 后显式下载运行时；better-sqlite3 13 的 Node-API 预编译模块已在真实 Electron 中验证，无需额外编译。

```sh
npm install
npx install-electron --no
npm start
npm test
npm run package:linux
npm run verify:ui -- --packaged
npm run verify:settings -- --packaged
npm run verify:theme -- --packaged
npm run verify:rest -- --packaged
npm run verify:shortcuts -- --packaged
npm run verify:update
npm run release:local
```

GUI 检查使用独立临时数据目录并断言实际配置路径，测试数据库不与正式记录混用。界面测试需要已有图形会话，缺少时明确报未验收。所有测试保持应用沙箱开启。

更新 GUI 检查通过实际安装 shell 入口和 Electron relaunch 验证升级，只在临时包中自动回答原生对话框。正式程序不包含自动批准更新的测试开关。
