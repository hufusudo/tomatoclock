- 成品 GUI 实际验证：沙箱开启、Node 不暴露、CSP、最小化期间完成入账、恢复后最新演出一次、休息结束手动闸门、未完成退出不入账、重开保留设置与记录、导入先预览后确认。

## 执行中的取舍与修正（按发生顺序）

1. Electron 44 改为首次运行时下载；better-sqlite3 13 自带 Node-API 预编译。显式安装运行时，真实模块验证成功后省去重建。风险：若平台不匹配，会在运行时/成品检查中失败。
2. GitHub 下载慢，使用 Electron 文档列出的 npmmirror CDN，保持同版本与包内官方 SHA256 校验。风险：错误镜像内容会被校验拒绝；不接受镜像自定义校验值。
3. CSP 放在共享 index.html 的 meta 中，同时约束网页和本地页面。风险：过严策略可能阻止资源加载，浏览器与成品 GUI 已验证。
4. 修改时长触发异步保存曾丢失首次开始点击。界面接收该请求并等待设置保存成功，仍在原用户手势内请求网页通知权限。风险：不正确等待可能提前/重复开工，真实 Electron 和延迟保存回归已验证。
5. 进程沙箱阻止 spawnSync，返回 EPERM 但 status 为 0。成品探针先断言进程错误，并在正常用户测试环境验证；应用 Chromium 沙箱保持开启。风险：否则可能将未运行的探针误判为通过。
6. Electron 原生 Wayland 的最小化/恢复接口受限；本机已存在 XWayland，选择仅本应用的 x11 后端。风险：依赖现有 XWayland，分数缩放显示可能与原生 Wayland不同；当前桌面已实际验证，可显式选择其他后端。
7. 成品启动会忽略测试入口参数，曾把一个演示番茄写进新建默认数据库。依据创建时间、唯一 UUID、时间/时长和全库内容确认只有本次演示数据，关闭状态检查后备份到 /tmp/tomatoclock-demo-backup-e9IK0W，仅移除该行并恢复默认 50/0/0，正式统计恢复为零。后续成品测试改用临时 XDG_DATA_HOME，并在任何测试写入前检查实际 profile 路径。风险：隔离失败会污染统计，当前测试明确断言目录归属。
8. 单实例锁改为在设置隔离 userData 路径之后获取，避免默认配置目录锁干扰。风险：顺序错误会导致不同配置/测试实例相互影响，已用先失败后通过的生命周期测试覆盖。

这些操作没有安装系统包，也没有修改 btrfs、内核、引导、KDE、shell 或关键服务配置。
